# Font data

The `*.json` files in this folder are glyph outlines extracted from the Roboto and
Roboto Condensed typefaces by `scripts/build-font-data.mjs`.

- **Source**: <https://github.com/googlefonts/roboto-2> (`src/hinted`)

Derived outline data keeps the same licence. Regenerate with:

```bash
node scripts/build-font-data.mjs
```
