# Dwibahasa

Bahasa Malaysia di akar, English di bawah `/en/`.

---

## Kenapa laluan, bukan subdomain atau kuki

Tapak ini belum ada domain. Laluan awalan tidak memerlukan apa-apa selain susunan fail, kekal
berfungsi selepas berpindah ke domain sebenar, dan memberi setiap bahasa satu URL yang boleh
dikongsi — sesuatu yang kuki atau `?lang=` tidak boleh beri.

## Slug turut diterjemah

`/en/harga` ialah halaman English pada alamat Melayu, dan pembaca English tiada cara meneka
alamat itu. Jadi:

| Melayu | English |
| :-- | :-- |
| `/` | `/en/` |
| `/harga` | `/en/pricing` |
| `/panduan` | `/en/guide` |
| `/akaun` | `/en/account` |
| `/terma` | `/en/terms` |
| `/privasi` | `/en/privacy` |
| `/bayaran/berjaya` | `/en/payment/success` |

`ROUTES` dalam `src/i18n/index.ts` ialah satu-satunya tempat kedua-dua pokok ditulis. Pemilih
bahasa membacanya untuk memetakan mana-mana halaman kepada pasangannya — bukan menghantar
pembaca balik ke laman utama.

## Susunan fail

```
src/
├─ i18n/
│  ├─ index.ts          Locale, jadual laluan, langFromUrl, swapLang
│  └─ ui/
│     ├─ common.ts      Nav, footer, label berulang
│     ├─ pages.ts       Salinan halaman pemasaran, panduan dan rasmi
│     ├─ studio.ts      Studio, komponen bil, salinan preset dan pelan
│     ├─ server.ts      Ralat API, nota cetakan, amaran susun atur
│     └─ index.ts       Gabungan + useTranslations
├─ components/pages/    Kandungan setiap halaman, sedar-bahasa
└─ pages/               Fail laluan tiga baris; /en/ mencerminkan akar
```

## Kunci yang hilang ialah ralat kompil

Setiap modul kamus mengisytiharkan Melayu sebagai objek `const`, kemudian menaip English sebagai
`Record<keyof typeof ms, string>`:

```ts
const ms = { 'nav.apps': 'Apps' } as const;
export type CommonKey = keyof typeof ms;
const en: Record<CommonKey, string> = { 'nav.apps': 'Apps' };
```

Kunci yang ditambah pada satu sisi dan terlupa pada sisi lain menjadi ralat taip, bukan ayat
Melayu yang muncul di tapak English. `npm run typecheck` berjalan dalam CI, jadi jaminan itu
nyata, bukan angan-angan.

## Pelayan pun berbahasa

Ralat API, nota cetakan yang dipulangkan bersama fail STL, amaran susun atur dan nama produk
pada resit Stripe semuanya mengikut bahasa pemanggil. Studio menghantar `lang` dalam setiap
permintaan; laluan API membacanya dengan `toLang()` dan menghantarnya ke `parseSpec`,
`layoutTag`, `buildNametag` dan `arrangePlate`.

Sebab itu pembeli English mendapat *"Magnet pockets cut Ø8.3 mm × 2.2 mm deep"* dan bukan
"Poket magnet dipotong…", dan dia kembali ke `/en/payment/success` selepas membayar.

## Menambah bahasa ketiga

1. Tambah kodnya pada `LANGS` dalam `src/i18n/index.ts`, dan satu lajur pada setiap baris
   `ROUTES`.
2. Tambah objek bahasa itu pada setiap modul dalam `src/i18n/ui/`. Pengkompil akan menyenaraikan
   setiap kunci yang tertinggal.
3. Salin `src/pages/en/` kepada awalan baharu; setiap fail hanya tiga baris.
4. `astro.config.mjs` → tambah kod pada `i18n.locales`.
